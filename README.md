### Featured projects

#### [JobScope — AI-powered job market analyzer](https://github.com/aliaffan-dev/job-market-analyzer)
A 9-page Streamlit analytics app built on **775,252** cleaned 2023 data-job postings: salary trends, in-demand skills, locations, and a skill-gap analyzer that ranks roles by how well your skills cover them. The "AI" is explainable: taxonomy-based skill extraction, TF-IDF ranking and a cross-validated salary model.

- **Salary model (full dataset):** Ridge regression, 5-fold CV — MAE **$26,079**, R² **0.389** (per-role median baseline: $30,470 / 0.188)
- **Engineering:** DuckDB data pipeline with a data-quality report, **275** pytest tests, Ruff and GitHub Actions CI
- **Stack:** Python · Streamlit · pandas · scikit-learn · DuckDB · Plotly

[**Live demo**](https://job-market-analyzer-cfbthyiqf47cx5happ5mhti.streamlit.app/) · [Code](https://github.com/aliaffan-dev/job-market-analyzer) &nbsp;<sub>The hosted demo runs on a 10% sample (78,460 postings).</sub>

#### [Customer Churn Prediction](https://github.com/aliaffan-dev/customer-churn-prediction)
Predicts which telecom customers are likely to leave, using the IBM Telco dataset (**7,043** customers) and a scikit-learn pipeline. Logistic Regression was selected over Random Forest, and the decision threshold was lowered to 6% to prioritise catching churners.

- **Test results:** ROC-AUC **0.84** · churn recall **0.97** · precision **0.37** (recall and precision at the 6% threshold)
- **App:** returns a churn probability, a risk level and a downloadable report
- **Stack:** Python · Pandas · Scikit-learn · Streamlit · Joblib

[**Live demo**](https://customer-churn-prediction-kfrwsiqjx64jjnxczoixav.streamlit.app/) · [Code](https://github.com/aliaffan-dev/customer-churn-prediction)
